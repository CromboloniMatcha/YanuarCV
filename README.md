# Yanuar Noor Wicaksono - CV site

Static site (HTML, CSS, JS, Bootstrap 5). No build step.

- Content: edit `assets/js/data.js` (operators, experience, certs, projects).
- Photo: add `assets/img/photo.jpg` (portrait, about 3:4). The placeholder disappears automatically.
- Projects: each card in `data.js` opens its `url` in a new tab (external site).
- CV download: `assets/docs/Yanuar_CV.pdf`.
- Preview locally: open `index.html`, or use VS Code Live Server.
- Deploy: push to GitHub, then Import Project on vercel.com (Framework: Other, no build command).
